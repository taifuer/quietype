# Quietype 配置指南

本文集中说明 Quietype 的站点设置、集成内容、安全与部署选项。安装与开发命令请先阅读仓库 [README](../README.md)。

## 基础设置

Quietype 自有选项集中在“外观 → Quietype 设置”。站点标题、菜单、隐私政策和额外 CSS 继续使用 WordPress 原生界面；旧版 Customizer 中的 Quietype 选项会自动迁移。

主题提供两个菜单位置：

- `primary`：顶部主导航
- `prefooter`：正文之后、Footer 之前的独立导航；未分配时不输出

建议创建 `/archive/` 页面并指定“文章归档”模板。主题优先按页面模板查找归档，因此已有站点使用其他固定链接也不会失效。友情链接页使用“友情链接”模板；普通页面、分类、标签、搜索和 404 按 WordPress 模板层级自动匹配。

阅读背景包含纸白、米杏和浅绿三种亮色方案，选择保存在浏览器 `localStorage`，不写 Cookie 或数据库。

## 文章与技术内容

主题通过标准 `the_content` 渲染文章，不修改编辑器保存的 Markdown 原文。WP Editor.md、KaTeX 和 Prism 均非强制依赖；使用 WP Editor.md 时，原始 Markdown 仍由插件保存在 `post_content_filtered`，主题只处理最终前台 HTML。

目录依据渲染后的 H2/H3 自动生成，章节锚点不会写回数据库。Prism 存在时只负责解析、语言标记与行号；亮色 token 配色、语言标签和中文复制按钮由 Quietype 提供。主题会检查正文，只在确实存在代码、公式、图表或图片时保留相关资源。

文章版权声明默认关闭。启用后可以选择 CC BY-NC-SA 4.0、CC BY-SA 4.0、保留所有权利或自定义文字，并配置署名与作者链接。许可证属于站点运营者的内容政策，启用前应确认与实际授权一致。

## 书籍

后台“阅读”使用 `book` 内容类型，分类和标签由管理员自行建立。记录支持作者、出版年份、出版社、ISBN、阅读月份、读完/在读/读过/待读状态、豆瓣评分、个人整星评价和简短点评；值得特别推荐的书可勾选“推荐标记”，封面右上角会显示不占版面的暖黄色五角星。管理员主动选择五星评价时会自动勾选推荐，但可在保存前手动取消；打开已有记录不会强制改写选择。

封面可以使用特色图或任意稳定的 HTTPS 图片地址；加载失败时回退到文字封面。公开书架位于 `/books/`，按阅读年份分组、月份倒序呈现。主题设置可指定默认展开年份数：默认 2，填写 0 时全部展开。旧 `/reading/` 会永久跳转到 `/books/`。

书籍标题可以链接到豆瓣、出版社或其他 HTTP(S) 资料页，留空时保持普通文字。书籍不建立独立详情页，后台查看操作会定位到书架中的对应记录。

编辑页接受豆瓣读书链接或条目 ID。“读取豆瓣资料”只生成标题、作者、出版社、年份、ISBN、评分和封面预览，确认后仍需点击“确认填入”。豆瓣页面或访问策略变化时，所有字段均可手工填写。

## 照片

后台“照片”使用 `photo` 内容类型维护 `/photos/` 年度图库。每条记录包含标题、HTTPS 展示图片、拍摄月份，以及可选的原图、地点、说明、尺寸、焦距、光圈、快门、ISO、相机和镜头。

页面按年份与月份倒序排列，默认展开年份数可配置：默认 1，填写 0 时全部展开。照片没有独立详情页，后台查看操作会定位到图库记录。展示图用于灯箱，原图仅在访客主动点击时请求；特色图片由 WordPress 自动生成响应式尺寸。

外链图库可配置 CDN 基础目录。主题按 `thumbs/年份/同名文件.webp` 查找网格缩略图，灯箱继续使用展示图，缺失时自动回退。仓库工具可以批量生成长边 1000px、质量 82 的 WebP：

```bash
php tools/generate-photo-thumbnails.php ../photos-cdn ../photos-thumbs
```

将输出的 `thumbs/` 上传到 CDN 的 `/photos/` 前缀，最终地址形如 `/photos/thumbs/2026/<uuid>.webp`。图片信息预览只读取尺寸与可用 EXIF，不读取或公开 GPS；远程图床清除 EXIF 时可以手工填写。

书籍页和照片页的中文标题、英文标识与简介均可在“内容页面”中修改。简介也作为归档 SEO 描述，留空时不输出。

## 友链

主题启用期间恢复 WordPress 原生“链接”管理，并提供链接状态、分类顺序和可选可达性检测。前台按照后台链接分类动态分组；数字顺序越小越靠前，空分类不显示。

自动检测默认关闭。启用后每天轮换检测最多五条可见链接，连续失败三次只进入后台“待确认”，不会自动在前台标记失联。管理员确认后才显示低调角标，恢复为“正常”即可移除。

## SEO、站点地图与隐私

未检测到主流 SEO 插件时，Quietype 输出 description、keywords、Open Graph、社交摘要和 Schema.org JSON-LD；启用专用 SEO 插件后停止整组输出，避免重复。文章描述依次使用自定义描述、手工摘要、自动摘要；社交图片依次使用特色图、正文首图、默认分享图。

站点地图统一使用 WordPress Core 的 `/wp-sitemap.xml`。没有独立详情页的书籍和照片记录会被排除，`/books/` 与 `/photos/` 归档会加入地图；`/sitemap.xml` 永久跳转到核心地图。

Quietype 不包含遥测、广告脚本或无条件 Cookie 横幅。主题会向 WordPress 隐私政策指南加入建议文本，但 Footer 入口默认关闭；发布并指定政策页后，可以在“站点与页脚”中主动启用。头像镜像、统计代码、外链图片及其他第三方服务仍需站点管理员在政策中说明。

## 性能与缓存

主题不加载网络字体，PhotoSwipe 本地分发。图片加载服从 WordPress Core 对首屏与延迟图片的判断，主题只补充异步解码、远程尺寸缓存和替代文字检查。

如使用 Nginx FastCGI 等整页缓存，可在 Web 服务器建立仅允许本机访问的 PURGE 入口，并在 `wp-config.php` 中定义：

```php
define( 'QUIETYPE_CACHE_PURGE_ENDPOINT', 'http://127.0.0.1/internal-purge/books' );
define( 'QUIETYPE_PHOTO_CACHE_PURGE_ENDPOINT', 'http://127.0.0.1/internal-purge/photos' );
```

保存、改变状态或永久删除记录后，主题会在请求结束前尝试清理对应归档；未定义常量时不发请求，失败也不会阻止内容保存。

评论头像默认使用 WordPress Gravatar。需要镜像时可在“访问”中填写可信基础地址，或使用过滤器：

```php
add_filter( 'quietype_avatar_base_url', function () {
	return 'https://avatar.example.com/avatar/';
} );
```

## 登录、评论与 WordPress 优化

Quietype 可统一登录、找回密码和重置密码页面样式，并启用自定义入口参数、算术验证码和 XML-RPC 认证保护。建议使用 `entry` 作为参数名及至少 24 位私有随机值；验证成功后浏览器获得最长 12 小时的 HttpOnly、SameSite 签名 Cookie。

入口保护启用后，默认入口、错误参数和未登录的 `/wp-admin/` 返回 404。请先保存完整入口地址，且不要把真实值写入仓库、截图或统计平台。也可在 `wp-config.php` 定义 `QUIETYPE_LOGIN_GATE_KEY` 与 `QUIETYPE_LOGIN_GATE_VALUE`，常量优先于后台设置。

公开评论使用十分钟有效的签名四位数字验证，并带蜜罐和短时节流。隐藏入口与验证码只能减少自动扫描，不能替代强密码、多因素认证、服务器限速、备份和及时更新。

“WordPress”设置可隐藏登录用户的前台管理工具栏、停止文章/页面/书籍的新历史版本，并为单作者站点关闭作者归档与匿名 REST 用户列表。已有历史版本不会被静默删除，需要管理员核对后单独确认。

## SMTP 与自定义代码

“邮件”设置可以让 `wp_mail()` 使用 SMTP，并发送测试邮件。支持 TLS、SMTPS、无加密连接、可选身份验证、自定义发件地址，以及管理员登录和新评论通知。建议使用邮箱服务商授权码，并优先在 `wp-config.php` 定义 `QUIETYPE_SMTP_PASSWORD`；正式使用前还应配置 SPF、DKIM 与 DMARC。

统计脚本和站点验证代码可写入 Head 或 Footer。编辑器只允许具备 `unfiltered_html` 权限的管理员保存可执行代码；样式仍建议使用“外观 → 自定义 → 额外 CSS”。

## 备份与迁移

书籍、照片、浏览量和主题设置均保存在 WordPress 数据库中。切换主题不会删除数据，但相关管理入口和路由会停止注册。主题使用 `book`、`photo`、`book_category` 和 `book_tag` 标识，启用注册同名类型的插件前应检查冲突。

升级、迁移或卸载前，请同时备份数据库、`wp-content/uploads`、服务器缓存配置及 `wp-config.php` 中的 Quietype 常量。
